As programs grow, the same few instructions appear in several places: greeting a user, working out a price, drawing a line of dashes. Copying them everywhere is slow, and a fix has to be repeated in every copy. A **function** is a group of instructions with a name. You write the group once, and then use its name whenever you want it to run. Using a function is called **calling** it.

A function can receive values to work with. They are called **parameters** where the function is written and **arguments** where it is called. A function can also give a value back to the code that called it: the **return value**. Writing a function does not run it. It runs only when it is called.

All four languages have functions. Java calls them methods and puts them inside classes. The languages differ in how functions are written, and in whether you must declare the types of the parameters and of the return value.
