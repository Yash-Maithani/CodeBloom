The programs so far have run every line, from top to bottom. Real programs often need to choose. Show "You can vote" only if a person is old enough. Add a delivery fee only if an order is small. A choice like this is called a **decision**: at that point, the program can go one of two ways.

Every decision depends on a **condition**: a question whose answer is either true or false, such as "is the age 18 or more?". When the condition is true, the program runs one group of instructions. When it is false, the program skips that group, and it can run a different group instead. Either way, the program then carries on with the instructions after the decision.

Conditions are usually comparisons: is this number bigger than that one, are these two values equal? C, C++, Java and Python write comparisons with almost the same symbols, such as `>=` and `==`. They differ in how they mark which instructions belong to each choice.
