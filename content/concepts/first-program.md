A **program** is a list of instructions for a computer. You write the instructions as text in a file. That text is called **source code**.

When the computer carries out the instructions, we say the program **runs**. It follows the instructions exactly as written, one after another, from the first to the last. It does not guess what you meant.

The text a program shows when it runs is called its **output**. Output is how you find out what a program did.

C, C++, Java and Python all work this way. They differ in what happens between writing the file and running it.
