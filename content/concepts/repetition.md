Many tasks repeat. Show the numbers 1 to 100. Ask for a password until it is right. Add up every price on a receipt. Writing the same instruction a hundred times is slow, and it breaks when the number changes. A **loop** repeats a group of instructions instead.

Each time the group runs is one **pass**. A loop needs a way to stop. Some loops stop when a condition becomes false, the same kind of yes-or-no question as in a decision. Others go through a fixed set of values and stop after the last one. A loop whose stopping condition never happens never ends. This is called an **infinite loop**.

C, C++, Java and Python all have both kinds of loop. They differ in how they spell them and in how they mark which instructions repeat.
