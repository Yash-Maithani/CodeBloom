A program's variables disappear when the program ends. To keep information, a program saves it in a **file**: a named piece of storage on the computer that stays after the program stops. A program can **write** text to a file and **read** it back, in the same run or in a later one.

Working with a file follows the same steps in every language: open it, use it, and close it. Opening can fail, for example when the file does not exist. In a text file all data is plain text, so a number read from it arrives as text and must be converted.

C, C++, Java and Python all work with files this way. They differ in the functions and types they use.
