A program often needs to remember information while it runs: a score, a price, a person's name. A **variable** is a name that a program uses to keep track of a **value**, a single piece of information such as the number 17 or a person's name. Once a value has a name, you can use the name wherever you need the value, and you can change the value while the program runs.

Names also make programs easier to read. `price` tells the reader what a number means; a bare `250` does not. And when a value changes, you change it in one place instead of everywhere it appears.

To give a variable a value, C, C++, Java and Python all use `=`. It is an instruction, not a statement of fact: work out the value on the right, then give it to the variable on the left. That is why `count = count + 1` makes sense in a program, even though it could never be true in maths.

Every value also has a **type**: what kind of value it is, such as a whole number, a number with a decimal point, or text. The type decides what you can do with the value and how the computer stores it. All four languages have types. They differ in where you write the type and in when a type mistake is noticed.
