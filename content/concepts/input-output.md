A program that only shows fixed text always does the same thing. Most useful programs also take in information while they run, and then respond to it.

Information that a program receives while it runs is called **input**. Input often comes from a person typing at the keyboard. Information that a program shows is output, which you have already seen. Input lets one program give different results for different people, such as greeting each person by name.

Whatever a person types is a sequence of characters. Turning the characters 1 and 7 into the number seventeen is a separate step. Some languages do it for you when you ask for a number, and some give you the characters and leave the conversion to you.
